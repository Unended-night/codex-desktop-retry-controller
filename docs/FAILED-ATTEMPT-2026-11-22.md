## 这次尝试包含什么

- 适配当前原生引擎的重试结构。
- 自定义重试与 HTTP 阶段超时的独立开关、参数、收据和部分成功发布。
- Python HTTPX 回环转发、app-server stdio 桥接、C# 进程入口及 Node 启动对照。
- 手动配置 HTTP 阶段期限，尝试覆盖完整响应头之前和未结束错误正文的等待，超时交回原生重试预算。
- 首次真实启动“无法加载组织设置”之后，修补一次性启动命令路由和 Windows 标准流转交。
- 后续修补 TLS 握手取消后的连接回收，并增加隔离检查。

这些工作仍没有得到可正常使用的真实桌面入口。功能拆分和分项验收没有隔离桥接层阻断桌面基本操作的风险。
